# Meal optimizer

Constrained optimization over 3 meals x 7 days: for each slot select compatible recipe, satisfy served eaters, ingredient quantities, per-day prep and budget envelope. Optimize total utility + ingredient reuse − estimated waste − repetition penalty. Deterministic greedy with backtracking fallback for MVP; infeasibility report instead of pretending budget always supports plan.
